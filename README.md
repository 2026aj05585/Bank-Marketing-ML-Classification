# Bank Marketing Subscription Prediction — Five-Model Comparison

## a. Problem statement

The objective is to build and compare five supervised classification models that predict whether a client of a Portuguese banking institution subscribes to a term deposit following direct-marketing contact. The target variable is `y` (`yes` / `no`).

The project includes model training, evaluation, saved model artifacts, and an interactive Streamlit evaluation application.

## b. Dataset description

- **Source:** UCI Machine Learning Repository, Bank Marketing dataset (dataset 222).
- **Selected file:** `bank-additional-full.csv`.
- **Records:** 41,188.
- **Original input features:** 20.
- **Target:** `y` (binary: yes/no).
- **Selected predictors:** 19. The `duration` field is excluded because it is known only after the call and would cause information leakage for a pre-call prediction use case.
- **License:** Creative Commons Attribution 4.0 (CC BY 4.0).
- **Citation:** Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306.

The data is split into training and test partitions using an 80:20 stratified split with random state 42. Categorical variables are one-hot encoded; numeric variables are median-imputed and standardized. The preprocessing steps are saved inside each model pipeline so the same transformations are applied during app evaluation.

## c. GitHub Repository Link

**Repository URL:** https://github.com/2026aj05585/Bank-Marketing-ML-Classification

Repository contents:

- `train.py` — downloads the official dataset, trains and evaluates all five models, and creates model, report, and test-data artifacts.
- `app.py` — Streamlit interface that loads saved models and evaluates an uploaded labelled CSV without retraining.
- `requirements.txt` — Python dependencies.
- `models/` — five saved fitted pipelines, generated by `train.py`.
- `test_data.csv` — held-out labelled test records, generated by `train.py`.
- `reports/` — metrics and confusion-matrix CSV files, generated by `train.py`.

## d. Models used and evaluation metrics

The following classifiers are implemented on the same training/test split:

1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors (KNN)
4. Gaussian Naive Bayes
5. Support Vector Machine (linear SVM / LinearSVC)

The training script calculates Accuracy, ROC-AUC, Precision, Recall, F1 Score, and Matthews Correlation Coefficient (MCC). Positive-class metrics use `yes` as the positive label.

The following results are from the held-out test set using the same 80:20 stratified split and random state 42 for all five classifiers.

### Observations on model performance

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Achieved 83.50% accuracy and the highest AUC (0.8009), recall (0.6466), F1 score (0.4689), and MCC (0.4011). It provides the strongest overall balance among the five evaluated models, particularly for identifying term-deposit subscribers. |
| Decision Tree | Achieved 84.18% accuracy, with an F1 score of 0.4688, very close to Logistic Regression. Its AUC (0.7812) and MCC (0.3986) are slightly lower, indicating marginally weaker overall performance on this test set. |
| KNN | Achieved the highest accuracy (89.33%) and precision (0.5481). However, its recall (0.3006) is considerably lower, meaning it identifies a smaller proportion of actual subscribers. Its F1 score (0.3883) and MCC (0.3535) are also lower than those of Logistic Regression. |
| Naive Bayes | Achieved 80.49% accuracy, the lowest among the five models. Its recall (0.6347) is relatively high, but precision (0.3172) is the lowest, indicating that a considerable proportion of its positive predictions are false positives. |
| Support Vector Machine | Achieved 83.31% accuracy and an AUC of 0.8007, close to Logistic Regression. Its recall (0.6455), F1 score (0.4656), and MCC (0.3973) are also competitive, although slightly below Logistic Regression. |
| **Overall winner for this dataset** | **Logistic Regression** is the strongest overall model based on this comparison. It achieves the highest AUC, recall, F1 score, and MCC, offering a better balance between identifying actual subscribers and limiting classification errors. KNN has higher accuracy, but its substantially lower recall makes it less suitable when identifying the positive `yes` class is important. |

**Live Streamlit application:** https://bank-marketing-ml-2026aj05585.streamlit.app/
The application provides:

- CSV upload for labelled test data.
- Classifier selection dropdown.
- Six evaluation metrics and a comparison table for all available saved classifiers.
- Confusion matrix and classification report.
- CSV download of evaluated metrics.

The app loads the fitted pipelines from `models/` and predicts on the uploaded test data. It does not call `.fit()` or retrain models.

**Live Streamlit application:** [https://bank-marketing-ml-2026aj05585.streamlit.app/]

## Run instructions

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train and create project artifacts

```bash
python train.py
```

This downloads the UCI archive and creates `models/`, `reports/`, and `test_data.csv`.

### 3. Run the app locally

```bash
streamlit run app.py
```

### 4. Deploy on Streamlit Community Cloud

Push the complete project to GitHub, including the generated model files and `test_data.csv`. In Streamlit Community Cloud, create a new app, select the repository and branch, and set the main file to `app.py`.
